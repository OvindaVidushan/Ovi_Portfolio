# 🌐 Personal Portfolio Website

This repository contains my personal portfolio website, built to showcase my projects, skills, and experience in Software Development, Database Engineering, and Data Science.

The portfolio highlights my academic background, technical skills, certifications, and completed projects.

---

## 🚀 Features

- Responsive portfolio design
- Projects showcase section
- Education timeline
- Certifications section
- Experience timeline
- Contact information
- Clean and modern UI

- JavaScript

- Typed.js
- EmailJS

- Font Awesome
